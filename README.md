# 🏦 Bank Account System

A simple **Bank Account Management System** built using **Object-Oriented Programming (OOP) in Python**.  
This project simulates how a real banking system works by allowing users to create accounts, deposit and withdraw money, manage PINs, and track transactions through a command-line interface.

This project demonstrates core Python concepts such as:
- Classes & Objects
- Encapsulation
- Dictionaries & Lists
- User Interaction
- Transaction Management
- PIN Security

---

# ✨ Features

- ✅ Create New Bank Accounts
- ✅ Secure 4-Digit PIN Generation
- ✅ Deposit Money
- ✅ Withdraw Money with PIN Verification
- ✅ Check Account Balance
- ✅ View Transaction History
- ✅ Change Account PIN
- ✅ Multiple Account Support
- ✅ Menu-Driven Console Interface
